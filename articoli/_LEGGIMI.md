# Come pubblicare un articolo

1. Clicca **Add file → Create new file** in questa cartella.
2. Nome del file = indirizzo della pagina, es. `vino-dell-etna.md` → `italiaprive.it/vino-dell-etna`
   (solo minuscole, numeri e trattini).
3. Incolla il modello qui sotto, compila, clicca **Commit changes**.
4. Dopo circa 1 minuto l'articolo è online, in cima alla home e alla sua categoria.

```
---
titolo: Titolo dell'articolo
descrizione: Una frase per Google e per le anteprime social
categoria: news
immagine: https://indirizzo-della-foto.jpg
data: 2026-11-15
---
Primo paragrafo.

Secondo paragrafo, anche con **grassetto**.
```

- `categoria`: news, tendenze, storie oppure eccellenze
- `immagine`: indirizzo di una foto online (consigliata)
- Per modificare un articolo: apri il file, matita, salva.
- Per toglierlo: apri il file, menu … → Delete file.
- I file che iniziano con `_` vengono ignorati.
